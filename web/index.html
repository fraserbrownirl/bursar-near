Verify a receipt

Level 1 runs here on every sol ui receipt: the page turns the atomic amount into a decimal and compares it with the receipt. npm run verify does that too, and it also runs the 1Click signature, the field rules, and the NEP-413 hash. None of this shows where the output was computed.

Level 2 and level 3

npm run verify:firmware
npm run verify:weights
npm run verify:weights -- "sol ui 5000 6"

Level 2 builds the firmware and runs the command in an RV32IM emulator. Level 3 runs the computer layers from the chip pack on CPU. Neither shows that the language model chose the call. The transcripts are under Model runs, and the video is at the bottom of this page.
