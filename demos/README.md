# Demos

Four payment scenes. The owner opens `bursar` and types a sentence. Each scene is one folder: its page (`README.md`) with the sections *What it is*, *What's real*, *What's staged*, *How it's proven*, then one *Run on* per run, plus the assets that page cites. `scripts/check-proofs.mjs` enforces the shape (it runs inside `npm run check:readme`). The camera document is [runsheet.md](runsheet.md); the registry every hash and link resolves against is `docs/hackathon/evidence.json`. Attacks prove the same way in [../attacks/README.md](../attacks/README.md). All four scenes and the attack film play as one video in [full-demo.mp4](full-demo.mp4) (5:10, list `full-demo.txt`).
